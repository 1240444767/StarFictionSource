****

**「StarBox」APP** 不同于其他小说阅读软件，本质是个空壳浏览器，需要**自行编写或导入书源**才能使用，其原理为：**解析小说网站的搜索页、详情页、目录页、正文页，提取相关信息**来显示给你看，该项目只是分享我自用的书源~  

> 本项目是「StarBox」的书源分享，APP 官方项目为：[下载地址](https://starbox001.dpdns.org/)

****

## 温馨提示：

所有书源均来自第三方小说网站，我只是将其整理聚合为书源（仅用于公益分享，**`请勿贩卖或用作商业用途`**），所以**无法保证可用性**，可能随时失效，因此建议大家对完本小说趁早**全本缓存+导出为 TXT 文件**，或者去网上下载全本 TXT 小说文件，免得书源失效后难受。。。  

> [!NOTE]
> 因为**精力有限**加上我现在主要还是看本地收藏的完本小说，所以 **`本项目书源较少，维护也不积极`**，因此**请勿过度依赖**本项目，想要更多书源的话建议去自己编写

> [!TIP]
> 各书源（小说网站）一般都会有一些**访问速率限制**（各不一样），如果访问频繁可能会触发限制（**封禁 IP / 弹验证**
